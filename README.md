# CIT 384 HW6 — Personal Resume

A personal resume page based on the provided HW6 starter HTML.

GitHub Pages: [View the resume](https://martianmashaal.github.io/cit384-hw6/)

The page uses an external stylesheet, a blue and gray color palette, and two Google Fonts: Lato and Merriweather. Font sizes and weights distinguish headings from body text.

Palette: https://superdesigner.co/resources/color-palettes

Only the HW6 steps are implemented. HW7 and HW8 are separate assignments.
